# Prácticas en Java - Programación IV

Bienvenido a este repositorio de prácticas y ejercicios desarrollados para la asignatura **Programación IV** de la **Tecnicatura Universitaria en Programación** en la **Universidad Tecnológica Nacional (UTN)**, correspondiente al año **2026**.

---

## 📚 Sobre este Repositorio

En este espacio se recopilan las guías de trabajos prácticos, ejercicios de consola, proyectos de aplicación y entregables desarrollados a lo largo del dictado de la materia.

### Organización del Código
El repositorio está estructurado en subcarpetas independientes. Cada carpeta contiene:
- El código fuente de la práctica o proyecto.
- Un archivo `README.md` detallado con las consignas, pautas técnicas y requisitos solicitados.
